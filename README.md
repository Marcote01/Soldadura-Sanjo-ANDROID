# Soldadura Sanjo Simulator - APK (Android)

WebView con el juego HTML adentro. Funciona sin internet (Tailwind, Font Awesome y
fuentes van empaquetados en app/src/main/assets/www).

Compilar sin instalar nada: subir todo a un repo de GitHub -> Actions -> "Compilar APK"
-> Run workflow -> bajar el artefacto SoldaduraSanjo-APK (app-debug.apk).

El juego se abre en horizontal. Tocar y mantener para soldar; mover el dedo para seguir la guia.
